Índice de Gini Espacial

Mede a desigualdade na distribuição espacial das escolas críticas entre diferentes áreas da cidade.

O que é o Gini?

Originalmente criado para medir desigualdade de renda, adaptado para análise espacial.

Varia de 0 (igualdade perfeita) a 1 (desigualdade máxima).

Curva de Lorenz Espacial

Área A: Desigualdade observada

Área A + B: Igualdade perfeita

Gini = Área A / (Área A + B)

Interpretação dos Valores

0.0 - 0.3 Baixa desigualdade
0.3 - 0.4 Desigualdade moderada
0.4 - 0.5 Alta desigualdade
0.5 - 1.0 Desigualdade extrema

Aplicação no CheckInfra

  • Gini = 0.25: Escolas críticas razoavelmente distribuídas
  • Gini = 0.45: Concentração significativa em poucos bairros
  • Gini > 0.55: Problema territorial grave, desigualdade extrema

Valores acima de 0.4 indicam necessidade de políticas específicas para territórios vulneráveis.

Fundamentação

Gini, C. (1912). Variabilità e mutabilità.

Aplicado em: análise de saúde pública, educação, desenvolvimento urbano.
